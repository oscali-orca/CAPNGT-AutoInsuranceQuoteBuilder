# Auto Insurance Quote Builder

## Project description
This app allows you to get an auto insurance quote based off of your risk details (age, prior claims, vehicle age, mileage) and your chosen package/deductible. Quotes can be saved for viewing and duplicated for editing.

(Pulled from assignment website https://cg-dcx-bootcamp-quotes.web.app/index.html)

A customer enters driver and vehicle details, selects coverage/deductible, compares three annual training estimates, and saves an immutable quote. Revisit saved quotes or duplicate them into editable drafts. Use seeded fictional customers.

Enter details: driver age, vehicle age, annual mileage, prior claims in the past three years.
Configure coverage: Basic, Standard, or Enhanced and a shared deductible for collision/comprehensive.
Compare: view coverage, deductible, and annual USD premium for all packages on the same inputs.
Save and explore: name and save a quote, reopen its stored prices, or duplicate to change inputs at current rates.

## Project setup:
React frontend, Java Spring boot backend, and Supabase PostgreSQL database.

Download or clone the repository. 
To start the frontend, cd into the ReactFrontend Directory and run "npm install"
Then, run "npm run dev"

To start the backend, ensure that Maven or some other dependency manager is installed and install all required dependencies.
Then, run the project from com/example/javabackend/JavaBackendApplication.java
